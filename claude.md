# CLAUDE.md — ClipBar (macOS Universal Clipboard Manager)

## Project Overview
A blazing-fast, ultra-lightweight, open-source macOS clipboard manager written in 100% native Swift (AppKit + SwiftUI). Summoned via `Cmd+Shift+V`, it presents a sleek Spotlight-style floating glassmorphic bar holding the last 500 copied items (text, images, hex colors, and code snippets).

## Core Performance & Privacy Constraints
1. **RAM Budget (< 30MB):** Never hold full resolution `NSImage` or raw binary blobs in memory. Store text/metadata in SQLite and write image blobs to `~/Library/Application Support/ClipBar/Blobs/` with downsampled thumbnails (`120px` max height).
2. **CPU Budget (< 0.1% Idle):** Poll `NSPasteboard.general.changeCount` every `0.4s` using a background timer with `0.1s` leeway. Exit immediately if `changeCount` has not changed.
3. **No Invasive Permissions:**
   - Use Carbon `RegisterEventHotKey` for global `Cmd+Shift+V` registration (requires zero macOS permissions).
   - Respect privacy markers: ignore clipboard reads containing `org.nspasteboard.ConcealedType`, `org.nspasteboard.TransientType`, or `org.nspasteboard.AutoGeneratedType`.
4. **500-Item Ring Buffer:** Automatically prune unpinned items beyond the 500th entry in SQLite and delete orphaned image files on disk.

## Tech Stack & Architecture
- **Language & Minimum Target:** Swift 6 / Swift 5.10, macOS 14.0+ (Sonoma or newer), Universal Binary (Apple Silicon & Intel).
- **UI Framework:** AppKit (`NSApplication` accessory mode with `LSUIElement = YES`, no Dock icon) + custom `NSPanel` hosting SwiftUI views via `NSHostingView`.
- **Window Management:** `FloatingPanel: NSPanel` configured with `[.nonActivatingPanel, .titled, .fullSizeContentView]`, `level = .floating`, `collectionBehavior = [.canJoinAllSpaces, .fullScreenAuxiliary]`.
- **Storage:** SQLite3 (native C API wrapper or SwiftData) located in Application Support.

## Content Classification Rules
- `.color`: Matches Hex (`#RGB`, `#RRGGBB`, `#RRGGBBAA`) or `rgb()/hsl()`. Render a visual color circle swatch next to the string.
- `.code`: Copied from IDE/Terminal bundle IDs (`com.microsoft.VSCode`, `com.jetbrains.CLion`, `com.apple.dt.Xcode`, `com.googlecode.iterm2`, `com.apple.Terminal`, `com.todesktop.230313mzl4w4u92`) OR contains high symbol/indentation density. Render with `Font.system(.body, design: .monospaced)`.
- `.image`: Captured from `.tiff` or `.png` UTI types. Deduplicate via SHA-256 hash.
- `.text`: Default fallback for plain/rich text and URLs.
